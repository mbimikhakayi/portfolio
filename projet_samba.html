Serveur de fichiers Samba B06

Projet école • Eleven Hole Star • 11/06/2026

Serveur de fichiers Samba membre du domaine Active Directory.

infoContexte

Le projet Eleven Hole Star est un projet de groupe où chaque binôme gère une partie de l’infrastructure. Mon groupe s’occupait de B06, le serveur de fichiers de l’entreprise fictive : un partage de fichiers réseau pour ses 40 employés.

01

Objectifs du projet

  • check_circleCréer les machines virtuelles Windows Server et Debian sous Proxmox
  • check_circleIntégrer le serveur Samba au domaine Active Directory
  • check_circleCréer deux espaces de partage séparés selon les groupes AD
  • check_circleAppliquer le principe du moindre privilège et sécuriser le protocole SMB
02

Mise en place

  1. Créer les VM sous ProxmoxUne VM Windows Server et une VM Linux Debian.
  2. Rejoindre le domaine ADAvec security = ADS, Samba délègue l’authentification au contrôleur de domaine B05. Le serveur ne stocke aucun compte.
  3. Créer les partagesDeux espaces isolés : [bureauetudes] pour les ingénieurs et [direction] pour la direction.
  4. Régler les droits sur deux couchesCôté Samba avec valid users, côté Linux avec chmod 2770. Les deux doivent être alignés.
  5. Sécuriser SMBmin protocol = SMB2 désactive SMBv1 et sa faille EternalBlue (WannaCry).

check_circleRésultat

B06 fournit un stockage partagé et sécurisé aux 40 employés, avec deux espaces isolés par groupes AD. Il est placé sur le VLAN 20 (172.18.20.40) et envoie ses journaux vers Graylog (B07).
