Systèmes Windows et virtualisation

Projet école • SISR • 07/11/2025 au 17/09/2026

Du poste client Windows 11 à une infrastructure Windows Server complète.

infoContexte

Cette partie de ma formation porte sur l’administration des systèmes Windows dans des machines virtuelles : d’abord le poste client, puis le serveur avec les services indispensables d’un réseau d’entreprise.

01

Objectifs du projet

  • check_circleVirtualiser des postes et des serveurs
  • check_circleAdministrer un poste Windows 11
  • check_circleInstaller les services DHCP et DNS avec leur redondance
  • check_circleMettre en place Active Directory et les GPO
02

Progression

  1. Virtualisation (nov. 2025 – fév. 2026)VMware Workstation : installation de Windows en VM, machines « propres » client et Windows Server 2022, clones liés.
  2. Windows 11 client (novembre 2025)Création d’utilisateurs en interface graphique, en CMD et par script, gestion des cartes réseau, RAID et partage de dossier.
  3. DHCP (février – mars 2026)Mise en place du service DHCP, d’un serveur de secours et d’un serveur routeur, avec un découpage VLSM.
  4. DNS (mars – mai 2026)Résolution de noms, zones de recherche directe et inversée, DNS secondaire, puis TP DNS et DHCP avec redondance.
  5. Active Directory et GPO (juin – sept. 2026)Retour sur les GPO, puis infrastructure complète : routage, NAT, agent de relais DHCP, DNS principal et secondaire, contrôleur Active Directory et contrôleur supplémentaire.
03

Outils et matériel

check_circleRésultat

Je sais monter une infrastructure Windows Server avec DHCP, DNS et Active Directory redondés, comme celle que j’administre au quotidien côté support chez AFNOR.
